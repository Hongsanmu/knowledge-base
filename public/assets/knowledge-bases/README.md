# Knowledge Base Assets

Store knowledge-base-specific visual assets here.

- `icons/`: small icons used by knowledge-base cards.
- `images/`: larger preview or cover images for knowledge bases.

Files in `public/` are served from the site root. For example:

```ts
icon: '/assets/knowledge-bases/icons/team.svg'
image: '/assets/knowledge-bases/images/team.svg'
```

## Project Overview

Documentation site / knowledge base built with [Fumadocs](https://fumadocs.dev) on Next.js App Router. Documentation content lives as MDX files in `content/docs/`. The site is statically exported (`output: 'export'`) and deployed to GitHub Pages at `note.hongsanmu.top` (CNAME).

## Commands

```bash
npm run dev          # Dev server at http://localhost:3000
npm run build        # Production build (static export to out/)
npm run start        # Start production server (serves out/)
npm run types:check  # Regenerate .source/, then type-check (fumadocs-mdx && next typegen && tsc --noEmit)
```

The `.source/` directory is auto-generated by `fumadocs-mdx` (runs on `postinstall` and before `types:check`). It is gitignored — never edit it directly. If imports from `collections/server` fail, run `npx fumadocs-mdx` to regenerate.

## Architecture

**Content pipeline:** `content/docs/` (MDX + meta.json) → `source.config.ts` (`defineDocs` collection definition) → `.source/` (auto-generated accessors, imported as `collections/*`) → `lib/source.ts` (Fumadocs `loader` wrapping the collection, plus helpers for page images).

**Layout system:**
- `app/layout.tsx` — Root: `<html>`, Inter font, `<RootProvider>`
- `app/(home)/` — Landing page with `HomeLayout`
- `app/docs/` — Documentation with `DocsLayout`, receiving `source.getPageTree()` for the sidebar
- `lib/layout.shared.tsx` — Shared layout options (nav title, GitHub URL) consumed by both layouts, driven by config in `lib/shared.ts`

**Key routes beyond docs:**
| Route | Purpose |
|---|---|
| `app/og/docs/[...slug]/route.tsx` | OpenGraph image per doc page (Next.js `ImageResponse`) |

**MDX components:** `components/mdx.tsx` wraps Fumadocs default MDX components, injected into doc pages via `<MDX components={getMDXComponents(...)} />`. Doc pages use `createRelativeLink(source, page)` for relative file-path links between pages.

**Knowledge base theming:** `components/docs-theme-provider.tsx` reads the current pathname and sets CSS custom properties (`--kb-primary`, `--color-fd-primary`, etc.) to theme each knowledge base differently. Theme definitions are in `lib/knowledge-base-themes.ts`, and knowledge base configurations (slugs, descriptions, icons, docsRoot mapping, sort order) are in `lib/knowledge-bases.ts`.

## Configuration

- `lib/shared.ts` — Site name, route paths, GitHub repo info. Update these for your project.
- `source.config.ts` — MDX collection `dir`, frontmatter schema (`pageSchema`/`metaSchema`), and remark plugins (`remarkSteps`).
- `next.config.mjs` — Uses `createMDX()` from `fumadocs-mdx/next` to enable MDX compilation. Static export via `output: 'export'`.
- `tsconfig.json` — Path aliases: `@/*` → project root, `collections/*` → `.source/*`
- Styling: Tailwind CSS v4 via PostCSS; `lib/cn.ts` re-exports `twMerge` for className merging

## CI/CD

`.github/workflows/deploy.yml` — On push to `main`: checks out code, runs `npm ci` (which triggers `postinstall` → `fumadocs-mdx`), runs `npm run build` (static export to `out/`), then deploys to GitHub Pages. Uses Node 22.

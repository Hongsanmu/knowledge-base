## 内容分类

知识库的内容按三个板块组织：

| 板块 | 用途 |
|---|---|
| 快速上手 | 搭建指南、工具说明、写作规范 |
| 运营流程 | 发布流程、复盘模板、协作节奏 |
| 参考资料 | 术语表、决策记录、常用模板 |

## 文件约定

- 每个板块一个目录，目录下使用 `.mdx` 文件
- 每个目录通过 `meta.json` 定义侧边栏结构和顺序
- 文件名即 URL slug，建议用英文小写 + 连字符

## 元数据

每篇文档在 frontmatter 中声明 `title` 和 `description`，用于页面标题、SEO 和最近文档列表。

# rust 生命周期是什么？

rust 中生命周期和语法参数都作为泛型参数存在， 但是生命周期不是一种类型。

不管在函数的输入还是输出参数上 `'a` 的意思是：👉 **这个引用 **`arr`** 至少在 **`'a`** 这段时间内是有效的（不会悬垂），也就是引用指向的数据在**`’a`** 内不会被释放。**

```rust
fn get<'a> (v: &'a T) -> &'a U
```

<Callout type="idea">
  'a 不是代表 v 能活'a 这么久，而是意味着 v 所引用的数据在'a 是有效的，
  所得到的返回值也是一个引用，那么&'a U 只能在'a 内使用，否则可能会失效
</Callout>

所以 `'a` 真正的含义是：`'a` 是一个**约束变量（lifetime parameter）**，表示：**所有标注为 **`'a`** 的引用，其“有效期必须 ≥ **`'a`**”**。

生命周期的主要用途是防止悬垂引用，用来表示一个引用有效的范围。

> 在 cow 的源码中， 修改了 cow 枚举内部的值，将引用clone 后，cow 的生命周期是否会改变？

<Callout type="warning">
  在生命周期标注中特别需要注意，也特别容易错的一个典型代码就是 `&'a mut T`
  的生命周期和数据绑定 ，那么 `T` 的可变借用就会持续在整个代码快里！！！
</Callout>

# 函数 ， 结构体， trait 实现等生命周期标注的含义

## 函数的生命周期参数 [step]

`fn fnction<'a> (v：&'a  V , u： &'a U) -> &'a T` 返回值的生命周期 ≤ 所有输入 `'a` 的生命周期（取交集）

- `'a` : **编译器推导出来的“所有约束中最小的那个生命周期”**
- &’a v ，’a表示 变量 v 的生命周期应该小于源数据的最大值，&‘a U 同理。
- &’a V ，’a 具有协变， 将一个生命周期教长的变量传递给一个生命周期较短的变量是可行的。

## 结构体中的生命周期 [step]

👉 **结构体的生命周期 ≤ 它内部引用的生命周期**: 结构体不能在其内部引用失效之后继续被使用

```rust
struct ImportantExcerpt<'a> {
    part: &'a str, // 结构体持有一个字符串切片引用
}
```

`'a` 是在声明：这个类型依赖外部数据。`'a` 的含义是：**这个结构体实例，不能活得比它里面引用的数据更久。** 换一种更“约束”的说法`part: &'a str`意思是：`part` 指向的数据，至少要活 `'a`

而：`structImportantExcerpt<'a>` ， 表示：这个结构体本身，最多只能活 `'a` ，S 不能比 `data` 活得更久。生命周期 `'a` **不是结构体的“寿命上限” 。**而是：结构体里引用的那块数据的生命周期

---

如果在结构体中定义一个 `* const T` ，可以通过设置 `PhantomData` 来约束 `struct` 的生命周期。

## impl 块的生命周期参数含义？ [step]

```rust
impl<'a> S<'a>{
    fn get(&self , v: &'a T) -> &'a U
}
```

- 限制传入参数的生命周：在函数的**参数**里使用 `'a`，意思是：传入这个函数的引用，它活得**必须至少和结构体内部的数据一样长**。

```rust
struct S<'a> {
    text: &'a str,
}

impl<'a> S<'a> {
    // other_text 的生命周期被标记为 'a
    fn is_same_length(&self, other_text: &'a str) -> bool {
        self.text.len() == other_text.len()
    }
}
```

<Callout type="idea">
  如果你打算把 other_text 保存到结构体里面，
  或者你的操作要求传入的数据必须和结构体同生共死，
  你就会加上这个标记。如果调用者传入了一个生命周期比 'a 短的临时变量，
  编译器就会报错，从而保护你。
</Callout>
+ 保证返回值的生命周期：在函数的**返回值**里使用了
`'a`，意思是：这个函数返回的引用，**不是从函数的局部变量来的，也不是仅仅和
**`&self`** 绑定，而是和结构体最初借用的那块数据绑定的。**

```rust
impl<'a> S<'a> {
    // 返回值的生命周期是 'a
    fn get_original_text(&self) -> &'a str {
        self.text
    }
}
```

<Callout type="idea">
默认情况下（生命周期省略规则），如果你写 `fn get_text(&self) -> &str`，返回的引用的生命周期会和 `&self`（即结构体实例本身）一样长。
但如果你显式写了 `-> &'a str`:

你是在告诉编译器：“返回值不依赖 `self` 的生命周期 ， 即使这个结构体实例被销毁了，只要原始数据还在，这个返回的引用就依然有效！”这就放宽了对返回值的限制。

</Callout>

- 打破默认的生命周期省略规则（Lifetime Elision）。Rust 有一套默认规则。但当一个函数有多个引用参数时，编译器会“蒙圈”，不知道返回值该和哪个参数的生命周期绑定。这时你就必须用 `'a` 来充当**连线员**。

```rust
impl<'a> S<'a> {
    fn find_match(&self, target: &str) -> Option<&'a str> {
        if self.text.contains(target) {
            Some(self.text)
        } else {
            None
        }
    }
}
```

<Callout type="idea">
`impl<'a> S<'a>` 明确告诉编译器：返回的字符串，其生命周期与传入的 prefix 相同，或者与结构体自身的生命周期 `'a` 相同。

在这里，我们将它与结构体的 `'a` 绑定。

</Callout>

## trait 生命周期参数的含义 [step]

<Callout title="trait A<'a> ">

```rust
trait A<'a> { ... }
```

| 写法          | 返回值生命周期      |                                                                                                 |
| ------------- | ------------------- | ----------------------------------------------------------------------------------------------- |
| `trait A`     | 跟 `&self`          |                                                                                                 |
| `trait A<'a>` | 跟 `'a`（外部数据） | **典型场景：** 这种写法常用于返回“外部数据”或“静态数据”。例如，结构体里存了一个外部引用的指针。 |

`trait A<'a>` 的 `'a` 表示：**这个 trait 的方法签名中，存在“必须与 **`'a`** 绑定”的引用关系** 。**这个trait 的实现和使用，都要依赖一个外部生命周期** `'a`。
理解为：“这个 trait 是关于某个生命周期 `'a` 的”。

</Callout>

### `'a` 约束什么？

> 约束 trait 方法里出现的引用

```rust
trait A<'a> {
    fn get(&self) -> &'a str;
}
```

含义：实现这个 trait 的类型，必须能返回一个**至少活 **`'a`** 的引用**

```rust
struct S<'a> {
    data: &'a str
}

impl<'a> A<'a> for S<'a> {
    fn get(&self) -> &'a str {
        self.data
    }
}
```

#### 这里的 `'a` 全部是同一个

```plain
trait A<'a>      ← trait 需要一个生命周期参数
impl<'a>         ← 声明这个生命周期
S<'a>            ← 类型本身也带这个生命周期
A<'a> for S<'a>  ← 把它们绑定在一起
```

意味着：返回值生命周期 = 结构体内部数据生命周期。如果 trait 不带 `'a` 。 这时生命周期会走**省略规则**

```rust
trait A {
    fn get(&self) -> &str;
}

等价于=>

fn get<'b>(&'b self) -> &'b str
```

👉 返回值被绑定到：`&self` 的生命周期

<Callout title="trait 上的 `'a` 不是“trait 活多久” 。而是：**trait 描述的“行为”涉及一个外部借用关系**" type="idea">

```rust
trait A<'a>
```

</Callout>

等价于：A 是一个“带生命周期参数的接口”。👉 只有当 `'a` 被具体化之后，这个 trait 才完整。

📌 使用时你必须指定 `'a`

```rust
fn use_trait<'a, T: A<'a>>(x: T) {
    ...
}
```

### trait 生命周期来自哪儿

```rust
traitA<'a> {
    fn get(&self) ->&'astr;
}
```

<Callout type="idea">
  `'a` 的真正含义是：**“返回值必须来自某个至少活 **`'a`** 的地方”**
</Callout>
